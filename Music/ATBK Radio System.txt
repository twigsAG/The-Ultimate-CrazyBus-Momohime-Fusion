[ATBK RADIO SYSTEM]
To add any custom songs to the Radio,
you will have to put a supported audio file of your choice here.
(Be it an .mp3, .ogg, .wav, etc etc.)
Any number of songs can be added to the in-game radio.
If the music you want isn't a supported file than you will have to convert it as such.

IMPORTANT NOTICE:
The game only supports English text characters, so please rename any song with unique language characters.
(i.e. 死亡金属放屁森林 => Death Metal Fart Forest)
